🚀 Smart Product Recommendation System
Personalized product recommendations in real time using cutting-edge AI!

Built with LLaMA 4 (Maverick-17B-128E-Instruct) by SambaNova Systems and real-time web search using the Serper API, this app delivers fast and accurate suggestions based on user preferences, budget, and product category.

🌟 Features
🔍 Real-time Market Analysis with Serper API

🧠 LLaMA 4 by SambaNova for intelligent decision-making

🎛️ Select from top product categories like Cameras, Laptops, Smartphones, and Smart Home Devices

💬 Add custom preferences to fine-tune recommendations

💡 Streamlit-powered UI for smooth interaction
